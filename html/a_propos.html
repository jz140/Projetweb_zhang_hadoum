À propos du site

Un site vitrine réalisé avec HTML, CSS et JavaScript.

Ce projet respecte une structure claire : une page HTML, une feuille CSS et un fichier JavaScript pour chaque page.

Choix de conception

Charte graphique

Bleu académique, blanc, cyan technologique et jaune électrique pour garder une identité moderne et cohérente.

Limites du cours

Le site utilise uniquement des balises HTML classiques, du CSS externe et du JavaScript simple basé sur les événements et le DOM.

Organisation

  • Dossier html : toutes les pages du site
  • Dossier css : un fichier de style par page
  • Dossier js : un script par page
  • Dossier img : les visuels utilisés
